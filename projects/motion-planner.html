01 — Overview

The project started with a review of industry motion planning (ROS / MoveIt!, Gazebo) and the literature surrounding their construction, swept-volume distance, continuous collision detection between rigid bodies, kinematics, statistically complete algorithms.

The planner is a library first. Portability across platforms was a priority from the start, as most existing planners only run on linux. The core targets .NET Standard 2.0 and the Unity front end is only one consumer of it.

A robot is modelled as a composition of axes, with forward kinematics provided by a tree walk. That lets one planner handle an arbitrary robot and its configuration space instead of a hard-coded arm.

02 — Architecture

Planners, samplers and collision checkers sit behind interfaces (IPlanner, ISampler, ICollisionChecker), so a strategy can be swapped without touching the robot model or the front end.
