WorldLoom

A worldbuilding tool that models a fictional world as a queryable, bitemporal knowledge graph. Every fact records when it was true in the world and when it was written down, allowing a project to keep a full reconstruction of its own history.

  • Append-only facts: nothing is updated or deleted
  • One command layer behind the web API and the MCP server
  • Compare any two points in time, restore any entity
  • Runs on my k3s cluster, deployed by Flux
