01 — Overview

With a theme of "stupid games", you can play human vs human, human vs AI, or set two AIs against each other, minimax strategies will sit in a looping stalemate forever; some humans will too. It was built to experiment with game mechanics and AI strategies, so the architecture is modular:

  • New AI strategy: extend GameSolverBase and plug it in.
  • New player type: implement IPlayer, define a configuration, hook up a factory and register it with the player service. It then shows up in the UI.
