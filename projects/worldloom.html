01 — Overview

Facts in Worldloom are stored as nodes (entities) and edges (links between them). All facts have a real world time at which they were created, changed or removed, and some have in fiction times as well.

Every fact is an assertion. Assertions are append-only. Nothing is ever updated or deleted, so "what did I think about this last Tuesday?" is an actionable query.

Composable fields allow entities to relate to typed data, including other entities. A combination of these relationships and back-links within prose allow for quick navigation of large fictional works, temporal fields allow for entities to be plotted on timelines, geographic fields allow for plotting on maps.

An MCP server gets access to the exact same toolkit that you do, allowing agents to quickly walk the knowledge graph and provide insights or summaries on semantically relevant areas of your world, destructive tools are guarded, even so, with the append only data model nothing is ever truly "lost".

03 — Architecture

Every operation, read or write, is one function in worldloom_core.commands. The HTTP API and the MCP server are simple adapters that call those commands and nothing below them.
